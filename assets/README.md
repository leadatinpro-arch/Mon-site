# Images et fichiers

Déposez vos fichiers ici en respectant les noms ci-dessous : ils apparaissent
automatiquement sur le site. Tant qu'un fichier manque, un emplacement
« Photo à venir » s'affiche à sa place.

Formats conseillés : `.jpg` pour les photos, `.png` pour la mascotte (fond transparent).
Pensez à alléger les images (moins de 500 Ko chacune si possible, par ex. avec squoosh.app).

| Dossier / fichier                       | Où ça s'affiche                                  |
| --------------------------------------- | ------------------------------------------------ |
| `lea.png`                               | Votre photo, page À propos (déjà en place)       |
| `eclipse/mascotte.png`, `mascotte-2.png`, `mascotte-3.png` | Les 3 poses de la mascotte (déjà en place) |
| `eclipse/affiche-1.jpg`, `affiche-2.jpg` | Affiche du festival et visuel prévention (déjà en place) ; ajoutez-en d'autres dans `js/pages.js` |
| `eclipse/photo-1.jpg` … `photo-8.jpg`   | La galerie photos des événements Eclipse         |
| `punch/…`                               | Logo, mascotte et photos PUNCH (déjà en place, recadrés depuis vos captures ; remplacez-les par les originaux pour une meilleure netteté en gardant les mêmes noms) |
| `360idcom/visuel-1.jpg` … `visuel-3.jpg` | La galerie 360idcom                             |
| `art/art-1.jpg` … `art-6.jpg`           | La galerie Art                                   |
| `sport/sport-1.jpg` … `sport-6.jpg`     | La galerie Sport                                 |
| `voyage/voyage-1.jpg` … `voyage-6.jpg`  | Le carnet de voyage                              |

La première image de `art/`, `sport/` et `voyage/` apparaît aussi au survol
des passions sur la page À propos.

Pour ajouter plus d'images, ou changer les légendes et les liens (Instagram,
Shotgun…), modifiez `js/pages.js`.
