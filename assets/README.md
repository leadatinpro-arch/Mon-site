# Images et fichiers

Déposez ici :

- `lea.png` : votre photo (déjà ajoutée, extraite du CV). Pour la changer, remplacez ce fichier en gardant le même nom.
- `cv-lea-datin.pdf` : votre CV. Le bouton « Télécharger mon CV » apparaît automatiquement dès que le fichier est présent.
- `projets/…` : les images de vos projets, à référencer dans `js/content.js` (champ `image`).
